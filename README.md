# Jude Alvarez — REDSHIFT Career Portfolio

A responsive career portfolio built with semantic HTML, CSS, and vanilla JavaScript. REDSHIFT turns the career exploration into an interactive, red-toned digital environment.

## Features
- Asymmetric full-screen title composition with original SVG signal geometry
- Compact section rail with keyboard-visible focus and mobile touch navigation
- Selectable three-stage career pathway with responsibilities, skills, tools, and next steps
- Interactive competency map and technology laboratory
- Keyboard-operable job role comparison tabs
- Original red palette retained from the project: `#900000`, `#700000`, `#400000`, `#260000`
- Responsive desktop and mobile layouts
- Reduced-motion support

## Run locally
Open `index.html` in a modern browser. For a local development server, use VS Code Live Server or another static file server.

## Customize
Edit `index.html` for portfolio details and content, `style.css` for colors and layout, and `script.js` for interaction data and behavior.
